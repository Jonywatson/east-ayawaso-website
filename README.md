# East Ayawaso constituency website

Website for Hon. Ahmed Baba Jamal, MP for East Ayawaso. **Draft, not yet approved for publication.**

The site is plain HTML, CSS and JavaScript in `site/`, so it can be hosted anywhere that serves static files.

## Preview

```
npm install
npm start
```

Then open http://localhost:8080.

## Adding or changing gallery photos

1. Put the original photo in `photos/`.
2. Add an entry to `photos/photos.json` with an `id`, `file`, `alt` text (what the photo shows, for screen readers) and `caption`. Add `credit` if the photographer or source must be credited, and `crop` to cut out part of the photo.
3. Run `npm run images`.

The script resizes each photo to three widths, converts it to WebP, strips hidden metadata such as GPS location, and rewrites the gallery in `site/gallery.html` and the preview on the Home page. Don't edit the markup between the `GALLERY` and `PREVIEW` markers by hand; it is overwritten.

## Phones

On screens narrower than 720px the menu becomes a tab bar fixed to the bottom of the screen, and the Home page priorities and photo preview become swipeable rows. Visitors can add the site to their home screen; the icon is generated by `node scripts/make-icons.mjs` into `site/icons/`.

- [ ] Fill in the bio, contact details, social links and privacy notice placeholders marked `[ ]`.
- [ ] Confirm permission to use photos credited to Parliament of Ghana and Hafiz TV.
